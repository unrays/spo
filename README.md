## Subobject Polymorphic Overlay Pattern (SPO)

This is the official GitHub repository for the Subobject Polymorphic Overlay pattern. It aims to provide the community with a way to contribute to this work. Plans are in place to add numerous examples showcasing its features, starting right now with this first one.
